# Handoff Documentation

`docs/` contains durable project knowledge that should be useful after the current student team leaves.

- `user-guide/`
- `development-guide/`
- `deployment-guide/`
- `testing/`
- `security/`
- `faq/`
- `decisions/`
- `investigations/`
- `recommendations/`

Presentations, iteration planning, iteration reviews, and retrospectives belong under `course/`, not here.

Formal stand-ups are GitHub Issues/comments.
