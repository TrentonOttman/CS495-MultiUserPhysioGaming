# Game Design Scope Decision

- Over one level possible in scope
- Each round is relatively brief, like in Pico Park
  - A couple minutes per level at most
- Scale with amount of players (2-8+)
- 2-D Puzzle Co-op game with mainly collabartive over competetive efforts
- 3 main sources of input (up, left, right) -> Sensor input can either count for a direction a a more unique fourth option. 
- Scope is feasible enough within given timeframe, but it can also be easily expanded open in the future with further levels or the later introduction of more game mechanics with or without the sesnor

Game Scope has been decided for our preliminary design purposes.
