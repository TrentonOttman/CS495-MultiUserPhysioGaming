# Colyseus investigation

- Server Authoritative.
- Cost: Free and open source, but we will have to host on the cloud or elsewhere.
- Server side would be written in typescript.
- Client side supports Unity, Godot, typescript, and native.
- It has not yet released to v1.0 yet, but remains mostly feature complete.
- Scales well vertically and horizontally.
- Offers real time state synchronization. We define room state, Colyseus handles synchronization
- The Colyseus API supports the joining and creation of rooms (multiplayer sessions)
- Uses WebSockets to communicate from the server to client
- Can run locally during development
