# Unity
- Slower startup and would be more taxing on Chromebooks
- Better for more interesting 3D games
- More robust overall and thus has more features to utilize
- Has a free tier which will likely work for our purposes
- Current prototype is set up in Unity already, so we might be able to salvage some of the existing works
- Have one team member with Unity experience already

# Godot
- Quicker startup and less taxing on Chromebooks
- Works for light 3D and good for 2D
- Open source and free
- Many people say it's relatively simple

# Current decision
- It was mentioned during the stand-up that Unity's API toolkit is more mature than Godot's as well. Thus, with the above pros and cons, we have decided to stick with Unity for now.
