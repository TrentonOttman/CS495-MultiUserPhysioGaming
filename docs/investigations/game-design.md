# Game Design Scope

- 3-D gameplay is what was historically done for this game
- Benefits include:
  - Better player visibility
  - Greater immersion & breadth of gameplay mechanics
 - Downsides include:
   - Assets creation & rendering
   - Would be tougher on low-end target devices

- 2-D design
- Benefits include:
  - Better time feasibility
  - TypeScript is easily suitable for 2-D
  - Simpler assets and mechanics
- Downsides include:
  - Fewer games to draw inspiration from, save Pico Park

- Co-op or competative?
- Comp is likely more incentive to be proactive/do better, but co-op is likely to be more fun for all the players

- Taking Heavy Inspiration from Pico Park
- Puzzle design, but also has relatively visible characters and scales with different player counts
