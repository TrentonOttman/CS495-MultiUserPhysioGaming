# Deployment Guide

## Prerequisites

- Node.js and npm installed
- Git installed

## Setup

Clone the repository:

```bash
git clone https://github.com/TrentonOttman/CS495-MultiUserPhysioGaming.git
```

Intialize and run the server:

```bash
cd server
npm install
npm start
```

The Colyseus server should now be running locally.
The Colyseus client should now be accesible at the port given by the terminal output.
